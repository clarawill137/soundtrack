# 🎵 Саундтрек

Расширение для SillyTavern: музыка из Apple Music под настроение сцены. После каждого поста маленькая модель (профиль подключения, по умолчанию тот, где в названии есть «Carbon» или «Карбон») читает последний фрагмент и решает, какое сейчас настроение. У каждого настроения свой плейлист.

Работает в двух режимах и сам выбирает нужный.

- **Режим ссылок** — без аккаунта разработчика Apple. Когда настроение сцены меняется, нота на экране подсвечивается. Тап по ноте открывает пульт, там кнопка «Открыть в Музыке»: плейлист открывается в приложении, музыка играет в нём по подписке и не обрывается, когда телефон заблокирован. В пульте есть и встроенный плеер Apple, но без входа внутри него он играет отрывки по 30 секунд, и личные плейлисты из медиатеки в него не грузятся (только общие, со ссылкой).
- **MusicKit** — когда рядом с расширением лежит `token.json` (см. ниже). Музыка играет прямо в таверне, плейлист меняется сам, в пульте обложка, трек и кнопки. Плейлист можно выбрать из своей медиатеки кнопкой, без ссылок.

## Установка

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions && git clone https://github.com/clarawill137/soundtrack'
```
Потом обнови страницу таверны. Обновление:
```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions/soundtrack && git pull'
```

## Плейлисты

«Расширения → 🎵 Саундтрек → Настроения и плейлисты». Тап по настроению раскрывает его: значок, название, подсказка модели («когда включать») и ссылка. Ссылку берёшь в Музыке: «Поделиться → Скопировать ссылку» у плейлиста или альбома. Модель выбирает только из настроений, у которых есть плейлист, так что можно начать с трёх-четырёх. Настроения можно добавлять свои и удалять лишние.

Если не хочется тратить запрос на каждый пост, «Как понимать сцену» переключается на «по словам»: бесплатно, но грубо.

## Как пользоваться

- **Нота** на экране: значок текущего настроения. Точка и кольцо — настроение сменилось или музыка ждёт тапа; полоски — играет. Тап открывает пульт, ноту можно перетащить.
- **Пульт**: что играет, кнопки «играть», «назад», «дальше» (в режиме MusicKit) или кнопка «Открыть в Музыке», все настроения кнопками, галочка «сам по сцене» и «🎧 Какая сейчас сцена?».
- **Сам включать музыку не начинает**: пока ты не нажала «играть» (или поставила паузу), расширение только запоминает настроение. Сменится сцена во время игры — плейлист сменится сам.
- Команда `/soundtrack`: без слов — пульт; `/soundtrack бой` — включить настроение; `?` — послушать сцену сейчас; `pause`, `play`, `next`, `on`, `off`.

На айфоне звук в браузере может стартовать только от тапа. Если при автоматической смене плейлиста Safari не дал звук, нота подсветится: один тап по ней, и музыка пойдёт. Громкость на айфоне меняется только кнопками телефона, поэтому затухания при смене там нет.

## MusicKit: полный автомат

Нужен платный аккаунт Apple Developer Program и подписка Apple Music.

1. В кабинете разработчика: **Certificates, Identifiers & Profiles → Identifiers → + → Media IDs**. Описание — любое (его Apple покажет при входе как название приложения), идентификатор вида `media.com.что-нибудь.soundtrack`, включить MusicKit, Register.
2. **Keys → +**: имя любое, галочка **Media Services**, Configure → выбрать этот Media ID, Register. Скачать файл `AuthKey_XXXXXXXXXX.p8` — **он скачивается один раз**, сохрани его в «Файлы». Десять символов в имени файла — это Key ID.
3. Team ID — десять символов на странице Membership.
4. В Termius одной командой (подставь свои ID и вставь внутрь текст файла `.p8` целиком):

```
docker exec -i sillytavern node /home/node/app/data/default-user/extensions/soundtrack/token.mjs --team TEAMID0000 --key-id KEYID00000 --key-stdin <<'EOF'
-----BEGIN PRIVATE KEY-----
...
-----END PRIVATE KEY-----
EOF
```

Скрипт сохранит ключ в `~/.soundtrack/` внутри контейнера (вне папки расширения, наружу он не отдаётся), подпишет токен на 180 дней, положит `token.json` рядом с расширением и спросит Apple, принят ли токен. Обнови страницу таверны, в настройках Саундтрека нажми «Войти в Apple Music».

Перевыпуск раз в полгода (расширение напомнит за две недели):
```
docker exec sillytavern node /home/node/app/data/default-user/extensions/soundtrack/token.mjs
```
Проверить, что лежит сейчас: та же команда с `--check`.

`token.json` и ключ в репозиторий не попадают (`.gitignore`).

## Что знает модель

Последние посты без плашек, тегов и картинок (по умолчанию три, не больше 3500 знаков с конца), список настроений с подсказками и то, что играет сейчас. Ей велено менять музыку, только когда сцена действительно сменилась. Свои указания — в поле «Свои указания модели». Если модель не ответила (фильтр, нет профиля), для этого поста настроение считается по словам.

Настроение чата хранится в его метаданных (`chat_metadata.soundtrack`), плейлисты и настройки — в настройках расширения. Из консоли и для других расширений доступно `window.Soundtrack` (`state`, `switchMood(key)`, `analyze({manual:true})`, `open()`).
